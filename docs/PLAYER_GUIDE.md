# Storyteller AI Player Guide

Create or select a chronicle from the lobby, then write your character's action in the turn composer.
The Storyteller response and committed table messages appear in the live play view.

Dice are rolled by the server and appear in the dice log. A saved chronicle can be resumed or loaded
as a separate branch; loading a save never overwrites its source branch.

Character sheets use the active ruleset's field schema. Numeric edits are versioned, and a stale edit
is rejected instead of silently overwriting a newer sheet.

The local app may show GM-only content in the host view. Do not copy private secrets into public chat.
