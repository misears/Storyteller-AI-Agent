# Storyteller AI Player Guide

Create or select a chronicle from the lobby, then write your character's action in the turn composer.
The Storyteller response and committed table messages appear in the live play view.

Dice are rolled by the server and appear in the dice log. A saved chronicle can be resumed or loaded
as a separate branch; loading a save never overwrites its source branch.

Character sheets use their selected template's field schema. Save the initial sheet, then link it
to a chronicle from Character sheets. Linked sheets cannot be edited or reverted directly.

## Experience and advancement

In the linked sheet, choose Earn XP / session award, Spend XP on edited stats, or Sheet correction.
For advancement, edit the proposed stats first, enter the XP cost and reason, and submit the request.
Submission does not change the saved sheet or XP balance. Earned, spent, and available XP are tracked
separately. XP awards cannot also change stats.

The AI Storyteller reviews the request against the selected rules and source pages. Unclear awards
or costs need more information, not a guessed price. The host human Storyteller can provide an
explicit ruling, request review, then confirm approval or rejection with a name and reason.
Only a positive AI review followed by human approval applies the change. Outdated requests must
be resubmitted; rejected requests do not spend XP. Requests and decisions remain on the sheet.

## PDF roles and book chronicles

Assign a role in PDF library when uploading or after upload: Core rules, Rules supplement,
Setting / flavor, Runnable chronicle, or Unclassified reference. Rules supplements extend an
installed base ruleset; flavor and scenario books are not converted into replacement mechanics.

Select a chronicle and open Chronicle sources to choose its ruleset and reference PDFs. For a
published chronicle, select a Runnable chronicle PDF and the current book page. Preview the pages
as the host, save, and play. The AI uses a bounded window of source pages with GM-only instructions,
not a complete automatic extraction of the book. Advance the current page as the table progresses.
Keep secrets out of player-facing chat and review the AI's interpretation of the source material.

The local app may show GM-only content in the host view. Do not copy private secrets into public chat.
